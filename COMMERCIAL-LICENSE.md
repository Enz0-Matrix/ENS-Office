# Коммерческое лицензирование ENS-Office

ENS-Office распространяется по модели двойного лицензирования.

## Вариант 1. GNU AGPL-3.0 — бесплатно

Полный текст: [LICENSE](LICENSE). Подходит, если вы готовы соблюдать
условия AGPL, в частности:

* при распространении программы (в том числе изменённой) — предоставить
  получателям полный исходный код под той же лицензией AGPL-3.0;
* при предоставлении доступа к изменённой версии по сети (веб-сервис,
  терминальный доступ) — предложить пользователям этой версии
  соответствующий исходный код;
* сохранять уведомления об авторстве и текст лицензии.

**Внутреннее использование в организации без распространения наружу
и без сетевого доступа третьих лиц не создаёт обязанности открывать
свои доработки.** Это покрывает большинство сценариев предприятий,
переходящих на отечественное ПО.

Бесплатно и без ограничений по AGPL для частных лиц и образовательных
организаций предоставляются все возможности продукта.

## Вариант 2. Коммерческая лицензия — по договору

Нужна, если вы:

* включаете ENS-Office или его части в свой продукт и не хотите
  раскрывать исходный код этого продукта;
* распространяете модифицированную версию под своими условиями;
* оказываете услуги на основе изменённой версии по сети и не хотите
  публиковать изменения;
* нуждаетесь в гарантиях, SLA, сертифицированной сборке, подписи
  пакетов вашим ключом, сопровождении по договору.

Коммерческая лицензия снимает обязательства AGPL для лицензиата.
Права на сторонние компоненты (MIT, Apache-2.0, OFL) сохраняются
в полном объёме — они и так разрешают такое использование.

### Что можно включить в договор

| Услуга | Содержание |
|---|---|
| Право на закрытое использование | Без обязательств AGPL, бессрочно или на срок |
| Техническая поддержка | agreed SLA, канал связи, сроки реакции |
| Доработки под заказчика | Приоритетные функции, интеграции, миграция |
| Сертифицированные сборки | Подписанные RPM для РЕД ОС, установщик без интернета |
| Внедрение и обучение | Развёртывание, инструкции, обучение сотрудников |
| Сопровождение реестра | Документы для Минцифры, сертификат совместимости |

## Модули pro

Отдельные дополнительные модули могут распространяться только
по коммерческой лицензии и не входить в состав AGPL-части.
Базовые возможности — работа с файлами, формулы, оформление,
восстановление данных — всегда остаются свободными: данные
пользователя никогда не «запираются» лицензией (ADR-008).

Перечень и уровень каждого модуля: `app/table/src/modules.ts`.
