# ENS-Office и требования к отечественному ПО

> Это рабочая памятка разработчика, а не юридическая консультация. Перед подачей
> заявки в реестр сверьтесь с действующей редакцией правил на сайте Минцифры
> и, по возможности, с юристом.

## Что требует закон и от кого

| Документ | О чём | Кого касается |
|---|---|---|
| 149-ФЗ, ст. 12.1 (в ред. 188-ФЗ от 2015 г.) | Единый реестр российских программ для ЭВМ и баз данных (ведёт Минцифры) | создаёт сам реестр |
| Постановление Правительства № 1236 от 16.11.2015 | правила реестра и **запрет закупать иностранное ПО** для госнужд, если есть аналог в реестре | госорганы и заказчики по 44-ФЗ |
| Постановление № 1478 и смежные (223-ФЗ) | приоритет российского ПО | госкомпании |
| Указ Президента № 166 от 30.03.2022 | с 01.01.2025 — **запрет иностранного ПО** на значимых объектах КИИ | органы власти, госкомпании, объекты КИИ |

Сам закон не запрещает пользоваться программой, которой нет в реестре. Но в
организациях, которые переходят на отечественное ПО, администраторы обычно
разрешают ставить **только ПО из реестра** или прошедшее их внутреннюю проверку.
Поэтому цель — **включить ENS-Office в реестр Минцифры**.

## Требования реестра (п. 5 Правил, кратко) и где мы сейчас

| Требование | ENS-Office сейчас | Что сделать |

| Сведения не составляют гостайну | да | — |

### Свободные компоненты
Мы используем только компоненты под разрешительными лицензиями (MIT, Apache 2.0,
OFL, LGPL — у системных библиотек Linux). Они **разрешают** коммерческое использование,
изменение и включение в свой продукт при сохранении уведомлений об авторстве. Свои
доработки мы делаем сами (форк движка IronCalc, интерфейс, оболочка), то есть можем
менять и сопровождать продукт без иностранных разработчиков, а это важно для экспертизы
реестра.

### Что настораживает экспертов и как закрыть
- **Код на GitHub (США).** Не запрещено, но лучше держать **зеркало в российском
  сервисе** (GitFlic, GitVerse) и указывать его как основное хранилище.
- **Сборка на GitHub Actions.** Для реестра важно, чтобы продукт можно было собрать
  самостоятельно: описать сборку на своём компьютере/сервере (это уже работает —
  `tools/env.sh`, `scripts/`).
- **Установщик Windows** по умолчанию может скачать WebView2 с серверов Microsoft,
  если его нет в системе. Для организаций — собрать вариант без скачивания
  (`webviewInstallMode: embedBootstrapper`/`offlineInstaller`). Для РЕД ОС вопрос не стоит.
- **Иконки Fluent (Microsoft, MIT).** Юридически можно, но для «отечественного» образа
  стоит со временем заменить на свои.

## Документы для заявки в реестр (по требованиям Минцифры)
1. Описание функциональных характеристик.
2. Руководство пользователя.
3. Инструкция по установке.
4. Описание процессов жизненного цикла и поддержки (как исправляем ошибки, обновления, контакты).
5. Сведения о стоимости (в т. ч. «бесплатно» для частных лиц и школ).
6. Документы о правах (автор/правообладатель), при использовании свободного ПО — их перечень.
7. Экземпляр программы или доступ для проверки экспертами.

Подача — на портале Госуслуг/сайте реестра (reestr.digital.gov.ru), бесплатно; экспертиза
обычно занимает несколько месяцев.

## Совместимость с РЕД ОС
У РЕД СОФТ есть программа проверки совместимости прикладного ПО с РЕД ОС
(сертификат совместимости). Наличие такого сертификата и записи в реестре заметно
облегчает согласование установки с администраторами.

## Ближайшие шаги
- [ ] Выбрать лицензию ENS-Office (ADR-008: бесплатно частным лицам и школам,
  коммерческие модули — по лицензии).
- [ ] Зеркало репозитория в GitFlic или GitVerse.
- [ ] Документы 1–4 (черновики может подготовить Claude по коду и истории изменений).
- [ ] Пакет RPM для РЕД ОС 7 и 8, подписанный ключом правообладателя.
- [ ] Установщик Windows без скачивания из интернета.
