## Что внутри

Первый рабочий шаг движка ENS-Table: прототип выбора основы, форк IronCalc и три улучшения движка.

### 1. Прототип №1: Univer или своя сетка с IronCalc (`prototypes/grid-bench`)
Сравнение на обезличенном синтетическом листе (1–50 тыс. строк, ВПР, ЕСЛИ, ОКРУГЛ, СУММ).
Univer на 50 тыс. строк: расчёт 67 с, правка 24 с, 728 МБ; xlsx у него платный.
Решение: своя сетка и форк IronCalc (ADR-004). Подробности: `docs/research/proto-01-grid-bench.md`.

### 2. Форк IronCalc v0.9.0 (`core/ironcalc`, git subtree squash)
Наши правки помечены комментарием «ENS-Office» и покрыты тестами `test_ens_*` (ADR-006).

### 3. ВПР / ГПР / ПОИСКПОЗ в 50–100 раз быстрее
Индекс первого столбца строится один раз за пересчёт, результаты совпадают с перебором.
50 тыс. строк с ВПР: ~0,56 с вместо ~60 с (`docs/research/engine-01-ironcalc-fixes.md`).

### 4. Формат «Общий» — не больше 15 значащих цифр, как в Excel
`6366933.539999999` → `6366933.54`. ОКРУГЛ авторы исправили сами в 0.9.0, мы добавили тесты на наши случаи.

### 5. Инкрементальный пересчёт
Правка пересчитывает только зависимые формулы. Правка одной строки на 50 тыс. строк: ~75 мс вместо ~1,2 с.
При любой неуверенности движок делает полный пересчёт: структурные изменения, «разливающиеся» массивы, `#ПЕРЕНОС!`, циклы.
Скрытие строк теперь сразу пересчитывает ПРОМЕЖУТОЧНЫЕ.ИТОГИ(1xx), как в Excel.
Подробности: `docs/research/engine-02-incremental-recalc.md` (ADR-007).
