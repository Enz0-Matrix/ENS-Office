# Как запустить ENS-Table на РЕД ОС (и другом Linux)

> Сначала уточните у ИТ-службы, можно ли запускать на рабочем компьютере
> программы, скачанные не из репозиториев организации.

## Какую версию брать

Тестовые сборки лежат на странице выпусков:
https://github.com/Enz0-Matrix/ENS-Office/releases (нужен вход в GitHub).

| Компьютер | Что скачать | Почему |
|---|---|---|
| РЕД ОС 8 и новее, Astra 1.8, Ubuntu 22.04+ | `ENS-Table_…_amd64.AppImage` | настольная версия: сохранение на место, восстановление после сбоя |
| **РЕД ОС 7.x** и другие системы с glibc старше 2.35 | `ENS-Table_…_browser.html` | настольной версии нужна более новая система (см. ниже) |
| Windows 10/11 | `ENS-Table_…_x64-setup.exe` | установщик |

Узнать свою систему:
```bash
cat /etc/redos-release
```
```bash
ldd --version | head -1
```
Если `ldd` показывает 2.34 или меньше — берите версию для браузера.

## Версия для браузера (РЕД ОС 7 и любые старые системы)

Один файл `ENS-Table_…_browser.html`, около 9 МБ. Установка, права администратора
и интернет не нужны.

1. Положите файл в любую папку, например в «Документы».
2. Откройте его двойным щелчком или так: правая кнопка → «Открыть с помощью» →
   Firefox, Chromium или Яндекс.Браузер.
3. Чтобы открыть книгу: «Файл» → «Открыть» → выберите .xlsx.
4. «Сохранить» скачивает книгу в папку «Загрузки». Браузер не может записать
   файл на место. Восстановления после сбоя в этой версии нет.

## Настольная версия (AppImage)

Команды выполняются в той папке, где лежит файл. Если терминал открыт из
папки с файлом, путь уже правильный, и `~/` в начале не нужен:
```bash
chmod +x ENS-Table_*_amd64.AppImage
```
```bash
./ENS-Table_*_amd64.AppImage
```
`~/` — это домашняя папка (`/home/имя`). Запись `~/ENS-Table…` работает, только если
файл лежит прямо в домашней папке.

Если появится ошибка про FUSE:
```bash
./ENS-Table_*_amd64.AppImage --appimage-extract-and-run
```

### Ошибка `GLIBC_2.29 not found` (и похожие)
Система старше, чем нужно настольной версии: окно программы построено на
WebKitGTK 4.1 и glibc 2.35, а в РЕД ОС 7 — glibc 2.28. Берите версию для браузера.

### Запуск на виртуальной машине через SSH
```bash
ssh -X пользователь@адрес
```
```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 WEBKIT_DISABLE_COMPOSITING_MODE=1 ./ENS-Table_*_amd64.AppImage
```
На сервере нужны `X11Forwarding yes` в `/etc/ssh/sshd_config` и пакет `xorg-x11-xauth`.
Через SSH окно рисуется по сети, поэтому может подтормаживать.

## Перенос файла с компьютера на виртуальную машину
Если пароли на компьютере и на ВМ разные, `scp` спросит пароль **пользователя ВМ**:
```bash
scp -o PubkeyAuthentication=no ENS-Table_0.1.6_amd64.AppImage edrennikov@10.9.1.46:~/
```
Можно и через файловый менеджер с SFTP.
