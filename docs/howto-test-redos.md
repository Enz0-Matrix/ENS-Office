# Как попробовать ENS-Table на РЕД ОС (и другом Linux)

> Сначала уточните у ИТ-службы, можно ли запускать на рабочем компьютере
> программы, скачанные не из репозиториев организации.

## 1. Скачать сборку
1. Откройте https://github.com/Enz0-Matrix/ENS-Office/actions (войдите в GitHub).
2. Выберите последний успешный запуск **CI** (зелёная галочка) нужной ветки.
3. Внизу страницы, в разделе **Artifacts**, скачайте `ens-table-linux` (zip).

Внутри три варианта, выбирайте любой:

| Файл | Что это | Права администратора |
|---|---|---|
| `ENS-Table_…_amd64.AppImage` | одна программа, без установки | **не нужны** |
| `ENS-Table-…x86_64.rpm` | пакет для РЕД ОС / Альт / Fedora | нужны |
| `ens-table_…_amd64.deb` | пакет для Debian / Astra / Ubuntu | нужны |

## 2. Запустить AppImage (без установки)
```bash
cd ~/Загрузки
unzip ens-table-linux.zip
chmod +x appimage/ENS-Table_*_amd64.AppImage
./appimage/ENS-Table_*_amd64.AppImage
```
Если появится ошибка про FUSE, запустите так:
```bash
./appimage/ENS-Table_*_amd64.AppImage --appimage-extract-and-run
```

## 3. Или установить RPM (если есть права)
```bash
sudo dnf install ./rpm/ENS-Table-*.x86_64.rpm
```
Пакет попросит библиотеку окна `webkit2gtk4.1` — в РЕД ОС 8 она есть в репозитории.

## Что проверить
То же, что на Windows: открыть копию рабочего xlsx, формулы по-русски (`=СУММ`),
сохранение (Ctrl+S), восстановление после «снятия задачи» (`kill -9` или системный монитор).
Особенно важно: как файл открывается и сохраняется в сетевых папках (SMB) —
там Р7 чаще всего теряет данные.
