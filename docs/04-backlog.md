# План работ ENS-Table (из отзывов пользователя)

Сделанное переносится в выпуски (GitHub Releases, тестовые сборки `v0.1.x-test`).

## Следующее
- Условное форматирование: при частичном удалении правила с формулой — пересчитывать ссылки, как Excel.
- Печать: сквозные строки в xlsx как в Excel (`Print_Titles`), разбивка широких таблиц по столбцам.
- Ввод дробей «1 1/2» как числа с форматом `# ?/?`.
- Журнал изменений: подсветка изменённых ячеек на листе, сравнение двух версий файла.

## Сделано в 1.0.0
- Скрытое при протягивании, копировании (только видимые при фильтре) и автосумме.
- Отбор фильтра сохраняется в xlsx (`<filterColumn>`).
- Высота строки подбирается под повёрнутый текст.
- Дроби в числовых форматах (`# ?/?`, `# ??/??`, `# ?/8`, `# ??/100`), категория «Дробный».
- Печать: размер бумаги, свои поля, по центру, заголовок (закреплённые строки) на каждой
  странице, число страниц; параметры страницы — в книге и в xlsx (`pageSetup`, `pageMargins`).
- Условное форматирование: рейтинг (5 звёзд, 3 звезды, 5 сердец), «дата между / вне дат».
- Печать: колонтитулы (номер страницы, файл, лист, дата; свой текст в записи Excel),
  область печати, листание страниц в предпросмотре; всё сохраняется в xlsx.
- Журнал изменений в файле (customXml): кто, когда и какие диапазоны менял; при открытии —
  что изменилось с вашего прошлого открытия и правки в другой программе.
- Снимки восстановления с меткой версии и запасной копией в xlsx: после обновления
  программы книга восстанавливается из копии.

## Темы

  «Транспорт», «Панцири», «Учительская», «Броня», «Круглые друзья»; свои темы из файла.
- Осталось: простая тёмная тема (для работы); «скрыть тему из списка» для встроенных.

## Идеи пользователя
- **Свой помощник** (вместо Скрепыша из Office 97 — свой персонаж, не копия), выключен
  по умолчанию, лёгкий (SVG + CSS), подсказывает по ошибкам формул и предлагает справку:
  - основной вариант (выбор автора) — **«У. Болт»**: болт-спринтер, скептик и саркастичный
    социофоб, больше всего любит, когда его кладут («ну, положили — и ладно»);
  - запасной — **«Эксцентрик»**: восторженный оптимист (свой рисунок, без чужих персонажей).
- **Пасхалки** (2–3, безобидные, без влияния на данные): например, `=ENS()` в ячейке
  показывает версию и благодарность; конфетти при первом сохранении книги на 1000 строк;
  тайное сочетание в «Сведениях» открывает экран авторов.

## ENS-Office целиком
- ENS-Table — первая программа пакета. Дальше: текстовый редактор (замена Word),
  презентации; позже — мобильные версии.

## РЕД ОС, реестр, распространение
- Проверка на «Муроме» (РЕД ОС 7.3) каждого выпуска; переход на РЕД ОС 8 — по ответу админов.
- Документы для реестра отечественного ПО (docs/05-otechestvennoe-po.md); зеркало на GitFlic.
- Установщик Windows без скачивания WebView2 (для компьютеров без интернета).
