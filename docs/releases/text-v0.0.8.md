ENS-Text 0.0.8 — пробная версия текстового редактора ENS-Office.
Работает без интернета, открывает и сохраняет .docx. Номер версии ENS-Text независим от ENS-Table; тег выпуска — `text-v0.0.8`.

**Новое по сравнению с 0.0.7**
- **Колонки** (Макет → Колонки): текст перетекает из колонки в колонку, разрыв колонки, неравные колонки, разделитель. Колонки из DOCX теперь видны на экране.
- **Несколько страниц на экране** (Вид): одна страница, несколько страниц рядом, по ширине окна.
- **Сравнение документов** (Проверка → Сравнить): два файла DOCX или версия из истории против текущего документа. Правки показываются по словам; их можно принять или отклонить по одной или все сразу. Исправления Word (`w:ins`/`w:del`) читаются и сохраняются.
- **Закладки** (Вставка → Закладка, Ctrl+Shift+F5): добавить, перейти, переименовать (ссылки обновляются сами), удалить с предупреждением. Ссылка «Место в документе» в окне гиперссылки, Ctrl+щелчок — переход.
- **Подписи** (Вставка → Ссылки → Название): «Таблица N – …» над таблицей, «Рисунок N – …» под рисунком по ГОСТ 7.32; номера пересчитываются сами. В DOCX — поле SEQ, как в Word.
- **Оглавление** (Вставка → Ссылки → Оглавление, 1–4 уровня): «СОДЕРЖАНИЕ» по ГОСТ 7.32, строки с точками и номерами страниц обновляются сами, щелчок по строке — переход. В DOCX — поле TOC, Word показывает его сразу.
- **Сноски** (Вставка → Сноска, Ctrl+Alt+F; концевая — Ctrl+Alt+D): номера ставятся сами, текст сноски — по двойному щелчку по номеру и подсказкой при наведении.
- **Примечания** (Проверка → Примечания, Ctrl+Alt+M): панель справа, ответы, «решено», переход, удаление с отменой.

**Исправлено**
- Закладки, сноски и примечания из файлов Word больше не теряются при открытии и сохранении (раньше закладки пропадали молча, сноски и примечания — с предупреждением).

Это пробная версия. Перед использованием на важных документах сохраняйте копию исходного файла и проверяйте результат в совместимом офисном редакторе.

**Что проверено:** автоматические тесты ENS-Text (в том числе круг «открыть — сохранить — открыть» DOCX для закладок, подписей, оглавления, сносок и примечаний), сборки Linux и Windows в CI.

**Что нужно проверить вручную:**
- Новые кнопки ленты (группа «Ссылки», примечания, сравнение, колонки) в Windows и на РЕД ОС 7.
- Открытие сохранённых файлов со сносками, примечаниями и оглавлением в Microsoft Word.
- Текст сносок внизу страницы пока не выводится (виден в подсказке и в Word после сохранения).
