ENS-Text 0.0.2 — пробная версия текстового редактора пакета ENS-Office. Работает без интернета, открывает и сохраняет .docx. Это не версия ENS-Table: у редакторов отдельные номера и теги (`text-vX.Y.Z`).

**Новое по сравнению с 0.0.1**
- Поиск и замена по оформлению: в панели поиска (Ctrl+F, Ctrl+H) кнопка «Формат» — искать по шрифту, кеглю, Ж/К/Ч/зачёркнутому; заменить только оформление или текст вместе с оформлением.
- «Вставка → По-русски»: сумма прописью (рубли, доллары, евро, тенге, бел. рубли), ФИО и должность по падежам, дата «29» октября 2026 г., срок в рабочих и календарных днях.
- Мастера служебных документов («Файл → Служебный документ…»): письмо, приказ, акт, протокол по ГОСТ Р 7.0.97-2016 и журнал регистрации с номерами.
- «Рецензирование → Совместимость с Word»: предупреждает, что может «поплыть» после отправки (шрифты без аналога, широкие и вложенные таблицы, рисунки редких форматов, дробный кегль, потери при открытии).
- Новые логотип и значок приложения. Название редактора — ENS-Text.

**Что важно знать**
- Склонение ФИО и должностей работает по правилам, без словаря: редкие фамилии проверяйте глазами.
- Календарь рабочих дней расчётный (праздники РФ, перенос выпавших на выходные по ст. 112 ТК РФ). Переносы из постановлений Правительства вносятся в «Поправки» вручную.
- Журнал регистрации хранится на этом компьютере.

**Пока нет**
- Слияние правок из копий, живая вставка из ENS-Table, «ночной лист», помощник «У. Болт», профиль ГОСТ «Свой».
- Установщики ещё не проверены на живых Windows и РЕД ОС 7.

**Файлы**
- Windows: `ENS-Text_0.0.2_x64-setup.exe`.
- Linux: `.AppImage` (без установки), `.deb`, `.rpm`.
- РЕД ОС 7: `ens-text-r7-0.0.2-1.x86_64.rpm` или `ENS-Text_0.0.2_redos7.tar.gz`.
- `SHA256SUMS.txt` — контрольные суммы.
