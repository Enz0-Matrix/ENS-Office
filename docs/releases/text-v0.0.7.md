ENS-Text 0.0.7 — пробная версия текстового редактора ENS-Office.
Работает без интернета, открывает и сохраняет .docx. Номер версии ENS-Text независим от ENS-Table; тег выпуска — `text-v0.0.7`.

**Новое по сравнению с 0.0.6**
- **Таблица из Excel с формулами:** Вставка → «Из Excel» (или перетащите файл .xlsx в документ). Формулы берутся из самого файла и пересчитываются при изменении чисел; если листов несколько — выбор листа. Формулы, которых в тексте нет (ВПР, ссылки на другой лист), остаются числами, программа об этом сообщает.
- **Итоги при обычной вставке:** Excel передаёт через буфер обмена только числа (Word так же вставляет из Excel одни значения). Итоговые строка и столбец распознаются и становятся формулами =SUM(ABOVE) и =SUM(LEFT).
- **Регистр** (кнопка Aa рядом с размером шрифта, Shift+F3): Как в предложениях, все строчные, ВСЕ ПРОПИСНЫЕ, Начинать С Прописных, иЗМЕНИТЬ рЕГИСТР — исправляет текст, набранный с нажатым Caps Lock. Без выделения меняется слово под курсором.
- **Межстрочный интервал** — значок с меню (1,0–3,0, интервал перед и после абзаца) вместо широкого списка. Группы «Шрифт» и «Абзац» — в две строки, как в Word.

**Исправлено**
- Окно «Сайт … хочет использовать шрифты вашего компьютера» больше не появляется: установленные шрифты находятся сами. Полный список — по кнопке «Найти остальные шрифты…» с пояснением.
- Значки на ленте были размытыми: малые сжимались, большие растягивались. Теперь у каждого значка рисунок под размер кнопки, линии плотнее.

Это пробная версия. Перед использованием на важных документах сохраняйте копию исходного файла и проверяйте результат в совместимом офисном редакторе.

**Что проверено:** автоматические тесты ENS-Text, настольный тест помощника РЕД ОС 7, сборки Linux и Windows в CI; файл Excel пользователя вставлен со всеми формулами.

**Что нужно проверить вручную:**
- Значки и выбор шрифта в Windows (масштаб экрана 125 % и 150 %) и на РЕД ОС 7.
- Вставка файла .xlsx из настоящего Excel с разными функциями.
- Колонки из DOCX сохраняются, но на экране текст пока идёт одной полосой.
