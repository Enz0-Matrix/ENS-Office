ENS-Text 0.0.6 — пробная версия текстового редактора ENS-Office.
Работает без интернета, открывает и сохраняет .docx. Номер версии ENS-Text независим от ENS-Table; тег выпуска — `text-v0.0.6`.

**Новое по сравнению с 0.0.5**
- **Таблицы из Excel с живыми формулами.** По Ctrl+V таблица из Excel приходит таблицей, формулы сохраняются: поменяли число — итоги пересчитались. В ячейке можно задать формулу как в Word («Формула…»: =SUM(ABOVE), =A2*B2, =СУММ(B2:B5), СРЗНАЧ, МИН, МАКС, ОКРУГЛ). В DOCX формула сохраняется полем, которое понимает Word.
- **Специальная вставка** (Ctrl+Alt+V): с исходным форматированием, только текст, таблица с формулами, таблица значениями.
- **Перенос слов** (Макет → «Перенос слов») — сохраняется в DOCX.
- **Подложка** (Макет → «Подложка…»): ЧЕРНОВИК, ОБРАЗЕЦ, КОПИЯ, ДСП или свой текст — по диагонали на каждой странице, печатается и сохраняется как подложка Word.
- **Выбор шрифта:** каждый шрифт показан своим начертанием, с пометками «кириллица», «аналог: …», «нет в системе»; поиск, недавние, шрифты системы по кнопке.
- **Лента как в Word:** одна высота на всех вкладках (лист не прыгает), крупные значки.
- **Линейки:** тоньше и чётче, с миллиметровыми делениями. Граница поля берётся по всей высоте линейки; отступы можно увести в поле до края листа; подсказки при наведении.

**Исправлено**
- При добавлении ссылки выделенный текст пропадал (Enter из окна доходил до документа). Теперь у ссылки есть подсказка «Ctrl+щелчок — открыть ссылку», а при нажатом Ctrl курсор над ней — «рука».
- Не было видно значка кнопки «Отобразить все знаки» (¶).
- После смены вкладки ленты списки шрифта и размера показывали «Calibri, 8» вместо шрифта под курсором.
- Колонки из DOCX пропадали при сохранении. Теперь они сохраняются; на экране текст пока идёт одной полосой.

Это пробная версия. Перед использованием на важных документах сохраняйте копию исходного файла и проверяйте результат в совместимом офисном редакторе.

**Что проверено:** автоматические тесты ENS-Text, настольный тест помощника РЕД ОС 7, сборки Linux и Windows в CI; подложка проверена в LibreOffice.
