ENS-Text 0.0.3 — пробная версия текстового редактора пакета ENS-Office. Работает без интернета, открывает и сохраняет .docx. Это не версия ENS-Table: у редакторов отдельные номера и теги (`text-vX.Y.Z`).

**Новое по сравнению с 0.0.2**
- **Разделы с разной ориентацией.** Документ, где страницы книжные и альбомные вперемешку, открывается как есть: у каждого раздела свои размер, ориентация и поля, листы разной ширины идут друг за другом. Пишется обратно в docx. «Макет → Разрыв раздела»; размер, ориентация и поля меняются для раздела под курсором.
- **Рисунки «за текстом» и «перед текстом».** Фирменные бланки с логотипом: рисунок встаёт на место (от страницы, поля или абзаца), в том числе в колонтитуле, и не раздувает его. Обтекание слева и справа. «Макет → Рисунок → Обтекание» меняет выделенный рисунок.
- **Обрезка рисунков из docx** (когда рисунок обрезан в Word, он показывается обрезанным, а не сжатым целиком).
- **Шаблоны документов:** «Файл → Создать из шаблона…» — письмо, приказ, акт, протокол, служебная записка, заявление, доверенность, отчёт о НИР, пустой документ по ГОСТ. «Мои шаблоны» — личные, хранятся только на этом компьютере, никуда не отправляются; «Файл → Сохранить как мой шаблон…».
- **Свой профиль ГОСТ:** «Проверка по ГОСТ → Изменить свой профиль…» — поля, шрифты, интервалы, отступ, номера страниц по регламенту вашей организации.
- **Читаемость по-русски:** «Рецензирование → Читаемость» — время чтения, индекс Флеша, длинные предложения, повторы, канцеляризмы.
- **Ночной лист:** «Вид → Чтение → Ночной лист» — светлый текст на тёмном листе для чтения с экрана; печать остаётся белой.
- Длинное предупреждение при открытии переносится по строкам и читается в любой теме.

**Что важно знать**
- Печать документа с листами разных размеров пока идёт по размеру первого раздела.
- Колонтитулы и нумерация страниц берутся из первого раздела и общие для всех.
- Обтекание «по контуру» считается квадратным; «сверху и снизу» остаётся рисунком в строке; фигуры и надписи (не рисунки) не переносятся — об этом сказано при открытии.
- Обрезка рисунков работает в окне на Chromium (Windows, РЕД ОС 7); в Linux-версии на WebKitGTK она может не сработать.
- Календарь рабочих дней расчётный; официальные переносы вносятся в «Поправки».
- Склонение ФИО и должностей работает по правилам, без словаря.

**Пока нет**
- Слияние правок из копий, живая вставка из ENS-Table, метки в файле, помощник «У. Болт».
- Установщики ещё не проверены на живых Windows и РЕД ОС 7.
