# Стартовые промты для сессий

Вставляются первым сообщением в сессию Claude Code. Общие правила лежат в `CLAUDE.md` (корень и каталоги редакторов).

## Текстовый редактор
```
Работаем над ENS-Text (app/text). Прочитай CLAUDE.md в корне и в app/text, docs/07-ens-text-ideas.md и последние коммиты ветки.
Задача на эту сессию: [например, пункты 1–3 рабочего списка].
Сначала кратко опиши план и какие файлы затронешь, дождись моего ответа, потом делай.
Каждое изменение с тестом Playwright, отдельный коммит, ветка, PR. Чего не смог проверить, напиши в описании PR.
```

## Редактор таблиц
```
Работаем над ENS-Table (app/table). Прочитай CLAUDE.md в корне и в app/table и docs/.
Сначала составь список: чего не хватает до полной замены Р7 (по документам, тестам и коду) и что в таблице формул/форматов расходится с Excel. Сохрани как docs/xx-ens-table-gaps.md и покажи мне. Код пока не меняй.
```

## Презентации
```
Начинаем ENS-Slides. Прочитай CLAUDE.md в корне и app/slides/CLAUDE.md.
Сделай только этап 0: подготовь docs/09-ens-slides-plan.md с вариантами по каждому пункту, ссылаясь на реальный код ENS-Text и ENS-Table, который можно переиспользовать. Задай мне вопросы, которые блокируют решения (не больше 7). Код не пиши.
```

## Как связать три части
- Общие правила только в корневом `CLAUDE.md`, каталожные файлы не повторяют их.
- Общий код (интерфейс, шрифты, диалоги) живёт в одном месте и меняется отдельными PR, чтобы ни один редактор не ломал другой.
- Каждый редактор ведёт свой `docs/*-ideas.md` и пишет общие решения в `docs/02-decisions.md`.
- Одна сессия, один редактор, одна ветка (`text/...`, `table/...`, `slides/...`).
