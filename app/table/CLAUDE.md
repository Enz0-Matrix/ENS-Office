# ENS-Table

Состояние: почти готов заменить офисный пакет Р7 и не сильно хуже Excel. Движок вычислений (форк IronCalc, Rust, `core/ironcalc`) собирается в WebAssembly командой `npm run engine` (`app/table/scripts/build-engine.sh`, результат в `src/engine-pkg`), интерфейс TypeScript, общий код интерфейса лежит здесь и используется другими редакторами.

## Правила
- Правки общего кода (`app/table/...`, который импортируют `app/text` и другие) делай в отдельном PR и перед слиянием прогоняй тесты всех редакторов.
- Формулы: сверяй результаты с эталоном Excel на тестовых наборах. Любое расхождение это баг, а не «особенность».
- Производительность: измеряй на больших файлах (`prototypes/grid-bench`). Не принимай правку, которая заметно замедляет прокрутку или пересчёт, без обоснования.
- XLSX: круг «открыть, сохранить, открыть» без потерь, неподдерживаемое не удалять молча.
- Сборка под РЕД ОС 7: Chromium 128, glibc 2.17+.
