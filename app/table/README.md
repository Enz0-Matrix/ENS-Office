# ENS-Table — редактор таблиц ENS-Office

Веб-интерфейс в стиле Excel 2021–2024 поверх движка `core/ironcalc` (наш форк,
собранный в WebAssembly). Позже этот же интерфейс встанет в оболочку Tauri.

## Запуск
```bash
source tools/env.sh            # из корня репозитория
cd app/table
npm install
npm run engine                 # собрать движок в src/engine-pkg (~7 минут в первый раз)
npm run dev                    # http://localhost:5173
```

## Что есть в версии 0.1
- Лента: Главная, Вставка, Формулы, Вид; иконки Fluent UI (MIT).
- Сетка на Canvas: рисуются только видимые ячейки; формулы, стили, ширины столбцов из xlsx.
- Активная ячейка: толстая рамка, подсветка номера строки и буквы столбца;
  в неактивном окне рамка бледнее, но видна (требование §1).
- «Фокус ячейки» (перекрестие) — Вид → Фокус ячейки или Ctrl+Shift+K (§2).
- Переход к ячейкам из формулы: Ctrl+[ (влияющие), Ctrl+щелчок по ссылке в строке
  формул, Alt+← — назад (§3).
- Горячие клавиши по физическим клавишам: Ctrl+C/V/X/Z/Y/B/I/U работают в русской
  раскладке (§5). Ввод через невидимое поле: работают IME, экранная клавиатура, вставка.
- Поиск команд и функций в заголовке (Alt+Q), с русскими и английскими названиями
  и терпимостью к опечаткам (§6).
- Открыть xlsx (Ctrl+O), сохранить копию xlsx (Ctrl+S — скачивание; надёжное
  сохранение поверх файла будет в оболочке Tauri).
- Строка состояния: Среднее, Количество, Сумма для выделения.
