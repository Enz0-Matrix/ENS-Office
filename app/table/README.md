# ENS-Table — редактор таблиц ENS-Office

Веб-интерфейс в стиле Excel 2021–2024 поверх движка `core/ironcalc` (наш форк,
собранный в WebAssembly). Позже этот же интерфейс встанет в оболочку Tauri.

## Запуск
```bash
source tools/env.sh            # из корня репозитория
cd app/table
npm install
npm run engine                 # собрать движок в src/engine-pkg (~7 минут в первый раз)
npm run dev                    # http://localhost:5173
```

## Настольная версия (Tauri)
Нужны Microsoft C++ Build Tools (компонент «Разработка классических приложений на C++»)
и Rust для MSVC: `rustup toolchain install stable-x86_64-pc-windows-msvc`
(закреплён за папкой `src-tauri` файлом `rust-toolchain.toml`).
```bash
npm run engine                  # движок в WebAssembly (один раз)
npx tauri dev                   # запуск с отладкой
npx tauri build --no-bundle     # src-tauri/target/release/ens-table.exe
npx tauri build                 # установщик (NSIS)
```
В настольной версии:
- **Открыть / Сохранить / Сохранить как** — настоящие файлы. Тип определяется по
  содержимому: документ Word, переименованный в .xlsx, не откроется как пустая таблица.
- **Сохранение атомарное**: временный файл → запись на диск → сверка → замена.
  Исходный файл не меняется до конца успешной записи; если его изменила другая
  программа после открытия — вопрос «Перезаписать?». Ошибки объясняются по-русски.
- **Восстановление после сбоя (§7)**: каждая правка за доли секунды попадает в журнал,
  снимок книги — раз в 10 минут (настройка) и после 30 секунд простоя. После аварийного
  закрытия — панель «Восстановление документов»: восстановленная и исходная версии рядом,
  «Решить позже», «Удалить временные файлы». Папка — `%LOCALAPPDATA%u.ens-office.tableecovery`.
- **«Сохранить изменения?»** при закрытии окна; другие книги открываются в новых окнах.

## Что есть в версии 0.1
- Русские названия функций (`=СУММ`, `=ВПР`, `=ЕСЛИ`…) и русская локаль (запятая,
  `;` между аргументами); английские имена (`=SUM`) тоже работают и показываются по-русски.
- Лента: Главная, Вставка, Формулы, Вид; иконки Fluent UI (MIT).
- Сетка на Canvas: рисуются только видимые ячейки; формулы, стили, ширины столбцов из xlsx.
- Активная ячейка: толстая рамка, подсветка номера строки и буквы столбца;
  в неактивном окне рамка бледнее, но видна (требование §1).
- «Фокус ячейки» (перекрестие) — Вид → Фокус ячейки или Ctrl+Shift+K (§2).
- Переход к ячейкам из формулы: Ctrl+[ (влияющие), Ctrl+щелчок по ссылке в строке
  формул, Alt+← — назад (§3).
- Горячие клавиши по физическим клавишам: Ctrl+C/V/X/Z/Y/B/I/U работают в русской
  раскладке (§5). Ввод через невидимое поле: работают IME, экранная клавиатура, вставка.
- Поиск команд и функций в заголовке (Alt+Q), с русскими и английскими названиями
  и терпимостью к опечаткам (§6).
- Открыть xlsx (Ctrl+O), сохранить копию xlsx (Ctrl+S — скачивание; надёжное
  сохранение поверх файла будет в оболочке Tauri).
- Строка состояния: Среднее, Количество, Сумма для выделения.
- §4 «Закреплённый формат»: заданный формат не меняется от ввода; в числовой ячейке
  `22.08` и `22,08` — число; в текстовой — текст как есть (и `=1+1` тоже).
  Если формат «Общий» сменился автоматически — подсказка «Вернуть «Общий»».
  Вид → «Распознавать даты» выключает распознавание дат при вводе.
- Ctrl+стрелки — к краю блока данных, Ctrl+Shift+стрелки — выделение до края.
