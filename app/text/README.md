# ENS-Tekst — текстовый редактор ENS-Office

Веб-интерфейс в стиле Word 2021–2024 на ProseMirror; формат файлов — .docx. Решение и границы — ADR-009.
Лента, реестр команд, шрифты, значки и стили берутся из `app/table/src` (общий код), поэтому для сборки
нужны зависимости обоих приложений.

## Запуск
```bash
cd app/table && npm ci          # общий код (значки, шрифты)
cd ../text && npm ci
npm run dev                     # http://localhost:5174
npm run check                   # типы
npm test                        # Chromium (Playwright): ввод, таблицы, docx туда и обратно, восстановление…
```
Тесты используют Playwright (установлен глобально или `npm i --no-save playwright && npx playwright install chromium`).
Образцы docx для тестов создаёт `python3 tests/make_fixtures.py` (нужен `python-docx`).

## Настольные версии
- **Tauri** (Windows, РЕД ОС 8, другие Linux): `cd app/text && npm ci && npx tauri build` (нужны Rust и, на Linux, WebKitGTK; как у ENS-Table).
  Локально не собирается без этих зависимостей — собирает CI (`desktop-text`, артефакты `ens-text-linux`, `ens-text-windows`).
- **РЕД ОС 7**: `cd app/text/redos7 && cargo build --release` — помощник `ens-text-r7`; окно рисует установленный Chromium
  (см. `app/table/redos7/src/main.rs`, там общий код). Пакеты (tar.gz, rpm) собирает CI.
- В обеих версиях: настоящие файлы и атомарное сохранение, восстановление после сбоя, «Открыть с помощью», открытие в новом окне.
  Документ, при открытии которого что-то не перенеслось, поверх исходного файла не сохраняется — только «Сохранить как».
- Проверка помощника: `npm run test:desktop` (настоящий помощник и интерфейс в Chromium, окна выбора файла подменены).

## Что есть в версии 0.1
- Абзацы, заголовки 1–6, начертание, шрифт, кегль, цвета, выравнивание, отступы, интервал, списки, таблицы, изображения,
  ссылки (Ctrl+щелчок — открыть), разрыв страницы (Ctrl+Enter), поиск и замена (Ctrl+F / Ctrl+H), масштаб (Ctrl+колесо), печать.
- Постраничная вёрстка: листы A4 и другие с полями, разрывы по строкам (не меньше двух строк абзаца на странице),
  заголовок не остаётся один внизу, разрыв страницы (Ctrl+Enter), таблицы рвутся по строкам, «Страница X из N».
- Размер страницы, ориентация, поля — сохраняются в docx. Сочетания работают в русской раскладке (по физическим клавишам).
- Открытие и сохранение .docx. Что не перенеслось, показывается над текстом; исходный файл не меняется никогда
  (в браузере «Сохранить» скачивает новую копию).
- Копия несохранённого документа каждые 1,5 с после правки лежит в IndexedDB: после сбоя программа предложит восстановить.
