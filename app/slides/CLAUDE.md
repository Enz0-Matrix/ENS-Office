# ENS-Slides (в разработке: стадия проектирования)

Состояние: кода нет. Сначала проектирование, кодирование только после утверждённого плана.

## Этап 0: документ `docs/09-ens-slides-plan.md` (без кода)
Опиши и предложи варианты с плюсами и минусами по каждому пункту:
1. Модель данных слайда (слои, фигуры, текстовые блоки, изображения, таблицы, диаграммы).
2. Формат файла PPTX (OOXML): что поддерживаем в первой версии, что сохраняем без изменений.
3. Что переиспользуем: общий интерфейс (лента, меню, диалоги), текстовый блок (ProseMirror из ENS-Text?), таблицы и диаграммы из ENS-Table. Что нельзя связывать между редакторами.
4. Показ презентации (полноэкранный режим, режим докладчика), экспорт в PDF.
5. Шаблоны и мастер-слайды, темы оформления.
6. Минимальная версия (MVP): создание слайдов, текст, фигуры, картинки, таблица, шаблоны, показ, открыть/сохранить PPTX.
7. План тестов (набор реальных PPTX), оценки по этапам.

## Правила
- Ограничения среды те же: Chromium 128, РЕД ОС 7.
- Общий код меняется отдельным PR (см. корневой `CLAUDE.md`).
- Решения записывай в `docs/02-decisions.md`.
